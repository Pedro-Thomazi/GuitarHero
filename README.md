# 🛒 Marketplace API & Frontend

Aplicação full-stack de marketplace onde usuários podem visualizar produtos, realizar pedidos de compra e gerenciar suas requisições.  
O sistema possui autenticação com **JWT**, controle de rotas protegidas e gerenciamento de pedidos vinculados ao usuário.

---

## 🚀 Tecnologias Utilizadas

### Frontend
- **React**
- **TypeScript**
- **React Router**
- **CSS Modules**

### Backend
- **Node.js**
- **Express**
- **MongoDB**
- **Mongoose**
- **JWT (JSON Web Token)**

---

## 📦 Funcionalidades

- 🔐 Autenticação de usuários (Login / Registro)
- 🛡 Proteção de rotas no frontend
- 🛍 Criação de requisições de compra
- 📄 Consulta de pedidos do usuário
- 📦 Gerenciamento de produtos
- 🖼 Upload e exibição de imagens de produtos
- 🧾 Histórico de compras vinculado ao usuário
